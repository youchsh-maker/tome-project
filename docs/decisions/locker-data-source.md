# 보관함·역 시설 데이터 출처

## Decisions

- 지하철역 물품보관함의 위치, 칸 크기별 실시간 빈 칸 수와 역 엘리베이터 정보는 서울교통공사 편의시설위치정보 API(data.go.kr 15143841)에서 받습니다. 보관함은 `/getFcLckr`, 엘리베이터는 `/getFcElvtr`를 쓰고, 둘은 역 코드(`stnCd`)로 연결합니다.
- 영문 역명은 서울교통공사 역명다국어표기 CSV(data.go.kr 15044232)의 공식 표기를 쓰고, 호선과 한글 역명으로 API 데이터와 연결합니다.
- 서비스 대상 역은 이 두 출처가 다루는 서울교통공사 관할 역으로 한정합니다.
- 서울교통공사 API에 없는 서울교통공사 운영 역(경기도 구간의 8호선 산성–모란, 7호선 철산·광명사거리, 3호선 지축)의 보관함은 행정안전부 전국 통합 공영 물품보관함 실시간 API(data.go.kr 15142469)에서 보충합니다. 위치(`/locker_info_v2`), 실시간 빈 칸(`/locker_realtime_use_v2`), 상세(`/locker_detail_info_v2`)를 보관함 ID로 연결하고, 서울교통공사 API에 이미 있는 ID와 "N호선 역명" 형태가 아닌 보관함(경전철, 관광지, 테스트 항목)은 쓰지 않습니다. 이 출처가 실패해도 서울교통공사 보관함은 그대로 보여 줍니다.

## Boundaries

- 9호선, 코레일 구간, 공항철도처럼 서울교통공사 관할이 아닌 역은 이 결정의 범위 밖입니다. 대상 역을 넓히는 일은 새 출처와 연결 방식을 따로 정해야 합니다.
- 보관함·엘리베이터의 상세 위치 문장을 어떻게 보여 줄지는 이 결정이 정하지 않습니다.

## Why

라커레이더의 핵심 흐름은 역 하나에서 빈 보관함과 엘리베이터를 함께 보여 줘야 합니다. 서울교통공사 API는 두 정보를 같은 역 코드로 주므로 데이터를 이름이나 좌표로 맞추다 생기는 오류가 없고, API 키도 하나면 됩니다. 실시간 갱신, 자동 승인, 개발 계정 하루 10,000건으로 첫 서비스에 충분합니다.

## Reconsider when

- 서울교통공사 관할 밖의 역(9호선, 공항철도 등)을 서비스 대상에 넣기로 할 때
- 서울교통공사 API가 실시간 빈 칸 필드를 더 이상 제공하지 않거나, 실제 호출에서 빈 칸 값이 지속적으로 비어 있을 때

## Still-rejected alternatives

- 행정안전부 API를 주 출처로 쓰는 방식 — 엘리베이터 정보가 없고, 2026-11-19 기준 서울 보관함 345곳이 모두 서울교통공사 쪽 T-Locker라 코레일·공항철도·9호선 보관함도 들어 있지 않습니다. 보충 출처로만 씁니다.
- 서울교통공사 물품보관함 위치정보 CSV(data.go.kr 15044234) — 위치만 있고 빈 칸 정보가 없습니다.

## Evidence worth preserving

- 2026-11-19 행정안전부 API 호출: 전국 386곳 중 서울교통공사 API의 337곳이 모두 들어 있고, 그 밖의 49곳은 경기도 서울교통공사 역 9곳, 서울식물원 5곳, 테스트 3곳, 의정부 경전철·수원·여수·통영 등이었습니다. 결과 코드는 `K0`이고, `numOfRows=2000`은 `K10` 오류를 돌려줘 1000을 씁니다.

- 2026-11-19에 data.go.kr 페이지에 포함된 Swagger 명세로 확인한 필드: `/getFcLckr`는 `usePsbltyLrtypeLckrCnt`·`usePsbltyMdtypeLckrCnt`·`usePsbltySmttypeLckrCnt`(대·중·소 사용 가능 칸 수), `totCrtrDt`(집계 기준 시각), `lckrRprsLocNm`·`lckrDtlLocNm`(한글 위치명), `LAT`·`LOT`, 요금·운영 시간을 줍니다. `/getFcElvtr`는 `vcntEntrcNo`(근접 출입구), `dtlPstn`(한글 상세 위치), 시작·종료층, `oprtngSitu`(가동 현황)를 줍니다. 보관함 응답에는 근접 출입구 필드가 없습니다.
- 2026-11-19 실제 호출: `/getFcLckr?stnNm=강남&dataType=JSON`이 `resultCode 00`과 3건(강남·강남구청 포함, 역명 부분 일치)을 돌려줬습니다. 칸 크기별 사용 가능 수와 `totCrtrDt`(예: `2026-11-19T11:20:06`)가 채워져 있었습니다. 요금(`utztnCrgExpln`), 사용 방법(`useMthdExpln`, 또타라커 앱 사용), 칸 크기 설명은 구조화된 값이 아니라 한글 문장입니다.
